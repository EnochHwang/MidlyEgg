Help

Making a Sale

Tap the logo to go to the main POS screen if not already there.

Select a category, then tap an item to add it to the cart. Tap an item again to increase its quantity. Long-press an item to decrease its quantity.

Cash Sale

Enter the amount of cash received. The amount of change due will be calculated automatically. Tap CASH to complete the sale.

Credit Sale

Tap CREDIT to complete a credit-card sale.

Clear a Sale

Tap CLEAR to remove all items from the cart and start over.

Summary

Open Summary from the gear menu to view sales totals and item quantities.

Today shows today's sales. Event shows the current or most recent selling event. On a weekend an event can span from Friday to Sunday. Month shows sales for the current month, and YTD shows sales for the current year.

In the items detail list, tap Today, Event, Month, or YTD to sort the items by quantity sold. The down arrow shows the currently selected sort.

Manage Transactions

Open Manage Transactions from the gear menu to review previous sales.

Use the From and To dates to select a date range. Transactions can be filtered by Payment type (cash or credit), Transactions or Items.

When All Transactions is selected the listing will be by transactions. When All Items or combinations of single items is selected the listing will be by items.

Manage Items

Open Manage Items from the gear menu to add or change items for sale.

Tap + Add Item to create a new item. Enter its Name, Category, Price, Inventory quantity, Display order, and whether the item is Active. An existing category can be selected from the dropdown. Typing in a new category name will create a new category. The display order number orders the items within that same category in the POS screen.

Edit an existing item to change its information or adjust inventory. Inventory can be increased or decreased by entering a positive or negative amount in Add Inventory.

Inactive items remain in the system but are not shown as products on the POS screen.

Inventory

Inventory is reduced automatically when a sale is completed.

Use Manage Items when inventory needs to be added or adjusted.

Create Report

Creating a report and saving it to a spreadsheet is available only on a desktop browser. The report allows you to specify a date range for the transactions to be included.

Offline Use

MidlyEgg POS can continue operating when the internet connection is temporarily unavailable. Sales are stored on the device and will be automatically archived when the connection is available again.
